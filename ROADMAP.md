# Roadmap

CodexBro is early-stage OSS. The near-term roadmap focuses on making the reference implementation easier to run, audit, and extend.

## v0.1.x

- Keep CI green for typecheck, build, E2E, and UI smoke.
- Improve Quick Start clarity for first-time contributors.
- Add more focused tests around worker allowlists and approval metadata.
- Expand documentation for Desktop bridge limitations and safe local setup.
- Collect external feedback through issues and discussions.

## v0.2.x

- Harden deployment guidance for self-hosted teams.
- Improve artifact browsing and task workspace cleanup controls.
- Separate experimental native-control backends from stable worker capabilities in the UI.
- Add more diagnostics for Codex app-server runtime attachment and native browser readiness.

## Later

- Supported Desktop-side bridge path if a stable public integration point becomes available.
- Better multi-worker scheduling and workspace-level policy controls.
- Maintainer automation for issue triage, release notes, and security review.
