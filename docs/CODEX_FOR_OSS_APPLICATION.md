## Eligibility

CodexBro is an early-stage public OSS reference implementation for local agent execution infrastructure. It helps developers learn how to pair a web control plane with trusted local workers, approvals, audits, files, artifacts, and CI-tested workflows. Although new, it is useful to the Codex/local-agent ecosystem.

## API Credits Usage

We will use API credits for OSS maintainer workflows: PR review, issue triage, release-note drafting, docs consistency checks, test-generation assistance, security review support, and project-specific quality gates for the public CodexBro repository.

## Anything Else

CodexBro was packaged as a maintainable OSS project with Quick Start docs, CI, release notes, contribution guide, security policy, issue templates, roadmap, good-first issue planning, and public feedback channels. We will use Codex to keep the repo easier to run and maintain.
