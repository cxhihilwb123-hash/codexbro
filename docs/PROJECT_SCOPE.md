# Project Scope

CodexBro is an experimental local-execution control plane for Codex-style agents.

## In Scope

- Pairing a web control plane with local workers.
- Workspace-scoped tasks, files, logs, approvals, audits, and artifacts.
- Safe defaults around local command execution.
- Reference implementations for worker lifecycle, retry, cancellation, and stale recovery.
- Experimental native Browser/Computer delegation with explicit readiness checks.

## Out of Scope

- Bypassing account login, CAPTCHA, payment, or platform security controls.
- Hidden browser or desktop automation without user consent.
- Proprietary Codex Desktop internals.
- Production warranty for experimental native-control backends.
- Hosted SaaS operations for third-party customer data.
