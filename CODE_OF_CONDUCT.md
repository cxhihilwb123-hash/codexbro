# Code of Conduct

CodexBro welcomes respectful, practical collaboration.

Participants should:

- Be kind and specific in reviews and issues.
- Assume good intent while still asking for evidence.
- Keep security-sensitive details out of public issues.
- Respect user privacy, local machine boundaries, and consent around automation.

Unacceptable behavior includes harassment, personal attacks, publishing private information, or pressuring maintainers to run unsafe local automation.

Maintainers may moderate issues, discussions, and pull requests to keep the project useful and safe.
